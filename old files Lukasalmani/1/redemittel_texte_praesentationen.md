# Redemittel für Texte und Präsentationen

Nov 5, 2026 · @Lukas

## 1. Einleitung – das Thema vorstellen

In der Einleitung nennst du das Thema, zeigst, warum es aktuell ist, und sagst, was dein Text erreichen will.

### A. Das Thema nennen

| Redemittel | Beispiel |
| --- | --- |
| In dem Text geht es um + Akk. | In dem Text geht es um den Pflegekräftemangel. |
| Es geht darum, dass … / … zu + Inf. | Es geht darum, wie man gesund lebt. |
| Der Text handelt von + Dat. | Der Text handelt von den Folgen der Digitalisierung. |
| Das Thema des Textes ist … | Das Thema des Textes ist das Homeoffice. |
| Im Mittelpunkt des Textes steht + Nom. | Im Mittelpunkt des Textes steht die Frage der Work-Life-Balance. |
| Der vorliegende Text beschäftigt sich mit + Dat. | Der vorliegende Text beschäftigt sich mit dem Klimawandel. |
| Der Text befasst sich mit dem Thema … | Der Text befasst sich mit dem Thema Ernährung. |
| In diesem Text wird … thematisiert. | In diesem Text wird die Integration von Migranten thematisiert. |
| Der Text setzt sich mit + Dat. auseinander. | Der Text setzt sich mit den Risiken sozialer Medien auseinander. |
| Der Autor / Die Autorin behandelt das Thema … | Die Autorin behandelt das Thema Mobbing in der Schule. |
| Der Text gibt einen Einblick in + Akk. | Der Text gibt einen Einblick in den Alltag einer Krankenschwester. |
| Ein wichtiges Thema, das im Text angesprochen wird, ist … | Ein wichtiges Thema, das im Text angesprochen wird, ist die Altersarmut. |
| Es wird die Frage behandelt, ob … | Es wird die Frage behandelt, ob Kinder ein Smartphone brauchen. |
| Der Text wirft die Frage auf, ob … | Der Text wirft die Frage auf, ob die Vier-Tage-Woche sinnvoll ist. |

### B. Die Aktualität betonen

| Redemittel | Beispiel |
| --- | --- |
| Heutzutage spielt … eine wichtige Rolle. | Heutzutage spielt künstliche Intelligenz eine wichtige Rolle. |
| In unserer heutigen Gesellschaft gewinnt … zunehmend an Bedeutung. | In unserer heutigen Gesellschaft gewinnt Nachhaltigkeit zunehmend an Bedeutung. |
| Immer häufiger wird über + Akk. diskutiert. | Immer häufiger wird über das Tempolimit diskutiert. |
| Das Thema … ist heutzutage besonders aktuell. | Das Thema Wohnungsnot ist heutzutage besonders aktuell. |
| Viele Menschen beschäftigen sich heutzutage mit der Frage, ob … | Viele Menschen beschäftigen sich heutzutage mit der Frage, ob sie Fleisch essen sollen. |
| In den letzten Jahren ist das Thema … immer wichtiger geworden. | In den letzten Jahren ist das Thema Datenschutz immer wichtiger geworden. |
| Ein aktuelles Thema, das viele Menschen beschäftigt, ist … | Ein aktuelles Thema, das viele Menschen beschäftigt, sind die steigenden Mieten. |

### C. Das Ziel des eigenen Textes nennen

| Redemittel | Beispiel |
| --- | --- |
| Im Folgenden möchte ich auf das Thema … eingehen. | Im Folgenden möchte ich auf das Thema Online-Lernen eingehen. |
| In diesem Text möchte ich mich mit + Dat. beschäftigen. | In diesem Text möchte ich mich mit den Vor- und Nachteilen von E-Autos beschäftigen. |
| Ziel dieses Textes ist es, … darzustellen. | Ziel dieses Textes ist es, verschiedene Meinungen darzustellen. |
| Der Schwerpunkt dieses Textes liegt auf + Dat. | Der Schwerpunkt dieses Textes liegt auf den Kosten. |
| Im Rahmen dieses Textes wird … genauer untersucht. | Im Rahmen dieses Textes wird die Situation in Österreich genauer untersucht. |
| Im Folgenden werden verschiedene Aspekte von … beleuchtet. | Im Folgenden werden verschiedene Aspekte von Teilzeitarbeit beleuchtet. |

### Grammatik

- **Häufiger Fehler:** ~~Der Text handelt sich um …~~ → richtig: *Der Text handelt von …* oder *Es handelt sich um …* (nur mit dem Subjekt „es“).
- **Feste Präpositionen:** handeln **von** + Dat. · sich beschäftigen **mit** + Dat. · sich auseinandersetzen **mit** + Dat. · es geht **um** + Akk. · eingehen **auf** + Akk. · diskutieren **über** + Akk.
- **Verb auf Position 2:** Steht ein Wort wie *Heutzutage* oder *Im Folgenden* am Anfang, kommt danach sofort das Verb: *Heutzutage **spielt** Bewegung eine wichtige Rolle.*
- **Plural beachten:** *Ein aktuelles Thema … **sind** die steigenden Mieten* – das Verb richtet sich nach dem Plural.

### Beispielsätze mit Übersetzung

| Deutsch | Persisch |
| --- | --- |
| Der Text handelt von den Folgen der Digitalisierung. | این متن درباره‌ی پیامدهای دیجیتالی‌شدن است. |
| Im Mittelpunkt des Textes steht die Frage der Work-Life-Balance. | در کانون این متن، مسئله‌ی تعادل میان کار و زندگی قرار دارد. |
| In unserer heutigen Gesellschaft gewinnt Nachhaltigkeit zunehmend an Bedeutung. | در جامعه‌ی امروز ما، پایداری روزبه‌روز اهمیت بیشتری پیدا می‌کند. |
| Im Folgenden möchte ich auf das Thema Online-Lernen eingehen. | در ادامه می‌خواهم به موضوع آموزش آنلاین بپردازم. |

## 2. Beginn – den ersten Punkt einführen

Mit diesen Redemitteln leitest du den ersten Gedanken oder das erste Argument ein.

### A. Kurze Einleitewörter

| Redemittel | Beispiel |
| --- | --- |
| Zu Beginn … | Zu Beginn stellt die Autorin ihre Familie vor. |
| Am Anfang des Textes … | Am Anfang des Textes wird eine Statistik genannt. |
| Zunächst … | Zunächst möchte ich die Vorteile nennen. |
| Zuerst (einmal) … | Zuerst einmal muss man die Kosten betrachten. |
| Als Erstes … | Als Erstes fällt auf, dass viele Jugendliche kaum schlafen. |
| Zuallererst … | Zuallererst sollte man die Situation analysieren. |
| Anfangs … | Anfangs war die Idee sehr umstritten. |
| An erster Stelle … | An erster Stelle steht die Gesundheit. |
| Im ersten Schritt … | Im ersten Schritt werden die Daten gesammelt. |

### B. Längere Satzanfänge

| Redemittel | Beispiel |
| --- | --- |
| Als Erstes sollte man erwähnen, dass … | Als Erstes sollte man erwähnen, dass das Projekt vom Staat finanziert wird. |
| Zunächst einmal ist es wichtig zu betonen, dass … | Zunächst einmal ist es wichtig zu betonen, dass jeder Mensch anders lernt. |
| Einleitend lässt sich sagen, dass … | Einleitend lässt sich sagen, dass das Thema sehr komplex ist. |
| Als ersten Punkt möchte ich … ansprechen. | Als ersten Punkt möchte ich die Arbeitszeiten ansprechen. |
| Zu Beginn ist es wichtig, auf + Akk. hinzuweisen. | Zu Beginn ist es wichtig, auf die hohen Kosten hinzuweisen. |
| Im ersten Abschnitt wird deutlich, dass … | Im ersten Abschnitt wird deutlich, dass die Patienten zufrieden sind. |
| Der erste wichtige Aspekt ist … | Der erste wichtige Aspekt ist die Sicherheit. |
| Ein erster Punkt, der berücksichtigt werden sollte, ist … | Ein erster Punkt, der berücksichtigt werden sollte, ist der Zeitaufwand. |
| Zuerst möchte ich auf + Akk. eingehen. | Zuerst möchte ich auf die Vorteile eingehen. |
| Zunächst kann man feststellen, dass … | Zunächst kann man feststellen, dass die Preise gestiegen sind. |
| Als Erstes fällt auf, dass … | Als Erstes fällt auf, dass Frauen weniger verdienen. |
| Am Anfang steht die Frage, ob … | Am Anfang steht die Frage, ob sich die Investition lohnt. |
| Beginnen wir zunächst mit + Dat. | Beginnen wir zunächst mit den Argumenten dafür. |
| Im Folgenden werde ich zunächst … erläutern. | Im Folgenden werde ich zunächst die Ursachen erläutern. |

### Grammatik

- **Verb auf Position 2:** *Zunächst **möchte** ich …* – nicht: ~~Zunächst ich möchte …~~
- **Als Erstes / Als Nächstes** werden großgeschrieben (substantivierte Zahlwörter).
- **Als ersten Punkt** steht im Akkusativ, weil es das Objekt von *ansprechen* ist: *Als ersten Punkt möchte ich … ansprechen.*
- **hinweisen auf + Akk.** · **eingehen auf + Akk.** · **beginnen mit + Dat.**
- Bei *Es ist wichtig, … zu + Infinitiv* steht der Infinitiv mit *zu* am Ende: *… auf die Kosten **hinzuweisen**.*

### Beispielsätze mit Übersetzung

| Deutsch | Persisch |
| --- | --- |
| Zunächst möchte ich die Vorteile nennen. | ابتدا می‌خواهم مزایا را نام ببرم. |
| Als Erstes fällt auf, dass viele Jugendliche kaum schlafen. | اولین چیزی که به چشم می‌آید این است که بسیاری از نوجوانان به‌سختی می‌خوابند. |
| Zu Beginn ist es wichtig, auf die hohen Kosten hinzuweisen. | در ابتدا مهم است که به هزینه‌های بالا اشاره شود. |

## 3. Hauptteil – weitere Punkte anschließen

Im Hauptteil verbindest du deine Argumente und zeigst die Reihenfolge oder einen Gegensatz.

### A. Einen weiteren Punkt hinzufügen (Verb direkt danach)

Diese Wörter stehen auf Position 1 – danach kommt sofort das Verb.

| Redemittel | Beispiel |
| --- | --- |
| Außerdem … | Außerdem spart man viel Zeit. |
| Darüber hinaus … | Darüber hinaus schützt Sport vor Krankheiten. |
| Des Weiteren … | Des Weiteren gibt es finanzielle Vorteile. |
| Ferner … | Ferner sollte man die Umwelt berücksichtigen. |
| Zusätzlich … | Zusätzlich bekommen die Mitarbeiter mehr Urlaub. |
| Weiterhin … | Weiterhin bleibt das Problem der Finanzierung. |
| Ebenso / Ebenfalls … | Ebenso wichtig ist die Unterstützung der Familie. |
| Zweitens / Drittens … | Zweitens ist das Angebot sehr günstig. |

### B. Einen weiteren Punkt mit „dass“-Satz einführen (Verb am Ende)

| Redemittel | Beispiel |
| --- | --- |
| Hinzu kommt, dass … | Hinzu kommt, dass die Mieten ständig steigen. |
| Dazu kommt noch, dass … | Dazu kommt noch, dass viele keine Zeit haben. |
| Nicht zu vergessen ist, dass … | Nicht zu vergessen ist, dass Kinder Vorbilder brauchen. |
| Außerdem sollte man beachten, dass … | Außerdem sollte man beachten, dass nicht jeder ein Auto hat. |
| Darüber hinaus ist zu erwähnen, dass … | Darüber hinaus ist zu erwähnen, dass die Stadt Fördergelder anbietet. |
| Des Weiteren lässt sich feststellen, dass … | Des Weiteren lässt sich feststellen, dass ältere Menschen digital aktiver werden. |
| Nicht zuletzt sollte man erwähnen, dass … | Nicht zuletzt sollte man erwähnen, dass Bewegung die Laune verbessert. |
| Ebenso wichtig ist die Tatsache, dass … | Ebenso wichtig ist die Tatsache, dass Pausen die Leistung steigern. |
| Ergänzend dazu lässt sich sagen, dass … | Ergänzend dazu lässt sich sagen, dass viele Firmen flexible Arbeitszeiten anbieten. |
| Darüber hinaus darf man nicht außer Acht lassen, dass … | Darüber hinaus darf man nicht außer Acht lassen, dass Homeoffice einsam machen kann. |

### C. Einen weiteren Aspekt benennen (Nomen)

| Redemittel | Beispiel |
| --- | --- |
| Ein weiterer wichtiger Punkt ist … | Ein weiterer wichtiger Punkt ist die Bezahlung. |
| Ein weiterer Aspekt, der berücksichtigt werden sollte, ist … | Ein weiterer Aspekt, der berücksichtigt werden sollte, ist die Sicherheit. |
| Ein weiterer Gesichtspunkt ist … | Ein weiterer Gesichtspunkt ist der Umweltschutz. |
| Ein weiterer Grund dafür ist … | Ein weiterer Grund dafür ist der Zeitdruck. |
| Ein weiterer Vorteil / Nachteil besteht darin, dass … | Ein weiterer Nachteil besteht darin, dass man ständig erreichbar ist. |
| Darüber hinaus spielt … eine wichtige Rolle. | Darüber hinaus spielt die Ernährung eine wichtige Rolle. |

### D. Die Reihenfolge zeigen

| Redemittel | Beispiel |
| --- | --- |
| Anschließend … | Anschließend beschreibt der Autor die Lösung. |
| Im weiteren Verlauf … | Im weiteren Verlauf des Textes werden Beispiele genannt. |
| Als Nächstes … | Als Nächstes geht es um die Kosten. |
| Im Anschluss daran … | Im Anschluss daran folgt ein Interview. |
| Daraufhin … | Daraufhin reagierte die Regierung. |
| Im nächsten Schritt … | Im nächsten Schritt wird das Ergebnis überprüft. |
| In einem weiteren Schritt … | In einem weiteren Schritt werden die Mitarbeiter geschult. |

### E. Einen Gegensatz zeigen

| Redemittel | Beispiel |
| --- | --- |
| Auf der einen Seite … auf der anderen Seite … | Auf der einen Seite ist das Auto bequem, auf der anderen Seite verursacht es Abgase. |
| Auf der anderen Seite … | Auf der anderen Seite gibt es auch Risiken. |
| Ebenso sollte berücksichtigt werden, dass … | Ebenso sollte berücksichtigt werden, dass nicht alle Menschen Internet haben. |

### Grammatik

- **Adverb auf Position 1 → Verb auf Position 2:** *Außerdem **spart** man Zeit.* – nicht: ~~Außerdem man spart Zeit.~~
- **„dass“-Satz → Verb am Ende:** *Hinzu kommt, dass die Mieten ständig **steigen**.*
- **Richtige Endung:** *im weiter**en** Verlauf* (Dativ, maskulin) – nicht: ~~im weiterem Verlauf~~.
- **bestehen darin, dass …** – *darin* verweist auf den folgenden „dass“-Satz.
- **außer Acht lassen** = nicht beachten; *Acht* wird hier großgeschrieben.

### Beispielsätze mit Übersetzung

| Deutsch | Persisch |
| --- | --- |
| Darüber hinaus schützt Sport vor Krankheiten. | علاوه بر این، ورزش از بیماری‌ها محافظت می‌کند. |
| Hinzu kommt, dass die Mieten ständig steigen. | به این موضوع اضافه می‌شود که اجاره‌ها مدام بالا می‌روند. |
| Ein weiterer Nachteil besteht darin, dass man ständig erreichbar ist. | یکی دیگر از معایب این است که آدم همیشه در دسترس است. |
| Auf der einen Seite ist das Auto bequem, auf der anderen Seite verursacht es Abgase. | از یک طرف ماشین راحت است، از طرف دیگر باعث تولید گازهای آلاینده می‌شود. |

## 4. Zitieren – fremde Aussagen wiedergeben

So gibst du wieder, was Experten, Studien, Zeitungen oder Institutionen sagen.

### A. Kurze Präpositionen (+ Nomen)

| Redemittel | Kasus | Beispiel |
| --- | --- | --- |
| Laut … | Dat. / Gen. | Laut dem Bericht / Laut des Berichts ist die Zahl gestiegen. |
| Nach … | Dat. | Nach Meinung der Experten ist das Risiko gering. |
| Gemäß … | Dat. | Gemäß dem Gesetz müssen alle Kinder geimpft werden. |
| … zufolge (nachgestellt) | Dat. | Der Studie zufolge schlafen Jugendliche zu wenig. |
| Nach Angaben von … | Dat. | Nach Angaben von Statistik Austria leben 9 Millionen Menschen in Österreich. |
| Laut Angaben + Gen. | Gen. | Laut Angaben des Ministeriums fehlen 20.000 Pflegekräfte. |
| Laut Aussage von … | Dat. | Laut Aussage von Ärzten ist Bewegung die beste Medizin. |
| Nach Ansicht / Auffassung von … | Dat. | Nach Ansicht von Fachleuten sollte man früher handeln. |
| Nach Einschätzung von … | Dat. | Nach Einschätzung von Ökonomen sinkt die Inflation. |
| Aus Sicht + Gen. / von … | Gen. | Aus Sicht der Wissenschaftler ist die Lage ernst. |
| Aus der Perspektive von … | Dat. | Aus der Perspektive von Eltern ist das Angebot zu teuer. |
| Den Angaben zufolge … | Dat. | Den Angaben zufolge wurden 300 Personen befragt. |

### B. „Wie“-Sätze (Verb am Ende, danach Verb – Subjekt)

| Redemittel | Beispiel |
| --- | --- |
| Wie … erklärt, … | Wie der Arzt erklärt, ist Schlaf sehr wichtig. |
| Wie … berichtet, … | Wie die Zeitung berichtet, wurde das Gesetz geändert. |
| Wie … betont, … | Wie die Ministerin betont, hat Bildung Priorität. |
| Wie … hervorhebt, … | Wie der Forscher hervorhebt, fehlen noch Daten. |
| Wie … darauf hinweist, … | Wie die Autorin darauf hinweist, sind Frauen stärker betroffen. |
| Wie aus … hervorgeht, … | Wie aus dem Bericht hervorgeht, steigen die Kosten. |
| Wie eine Studie zeigt, … | Wie eine Studie zeigt, macht Musik glücklich. |
| Wie … zum Ausdruck bringt, … | Wie der Autor zum Ausdruck bringt, ist er skeptisch. |
| Wie … deutlich macht, … | Wie die Statistik deutlich macht, gibt es weniger Geburten. |

### C. Studien und Untersuchungen

| Redemittel | Beispiel |
| --- | --- |
| Einer Untersuchung zufolge … | Einer Untersuchung zufolge essen Kinder zu viel Zucker. |
| Den Ergebnissen einer Studie zufolge … | Den Ergebnissen einer Studie zufolge arbeiten viele Menschen am Wochenende. |
| Einer aktuellen Studie nach … | Einer aktuellen Studie nach nutzen 90 % der Jugendlichen täglich soziale Medien. |
| Aus einer Studie geht hervor, dass … | Aus einer Studie geht hervor, dass Lesen den Stress reduziert. |
| Die Untersuchung kommt zu dem Ergebnis, dass … | Die Untersuchung kommt zu dem Ergebnis, dass Homeoffice produktiv ist. |
| In der Untersuchung wird festgestellt, dass … | In der Untersuchung wird festgestellt, dass Männer seltener zum Arzt gehen. |
| In dem Bericht wird darauf hingewiesen, dass … | In dem Bericht wird darauf hingewiesen, dass die Luftqualität schlechter wird. |

### D. Personen und ihre Meinungen

| Redemittel | Beispiel |
| --- | --- |
| Experten sind der Ansicht, dass … | Experten sind der Ansicht, dass Kinder mehr Bewegung brauchen. |
| Fachleute vertreten die Auffassung, dass … | Fachleute vertreten die Auffassung, dass die Reform zu spät kommt. |
| Wissenschaftler weisen darauf hin, dass … | Wissenschaftler weisen darauf hin, dass das Eis schneller schmilzt. |
| Der Autor vertritt die Meinung, dass … | Der Autor vertritt die Meinung, dass Schulen digitaler werden müssen. |
| Die Verfasserin macht deutlich, dass … | Die Verfasserin macht deutlich, dass Pflege mehr Anerkennung verdient. |
| Der Aussage von … nach … | Der Aussage des Direktors nach wird die Schule renoviert. |

### Grammatik

- **zufolge** steht immer **nach** dem Nomen: *Der Studie zufolge …* – nicht: ~~Zufolge der Studie …~~
- **laut** steht mit Dativ oder Genitiv: *laut dem Experten / laut des Experten*. Ohne Artikel bleibt das Nomen oft ohne Endung: *laut Bericht*.
- **„Wie“-Satz am Anfang:** Der ganze Nebensatz ist Position 1, danach folgt sofort das Verb: *Wie die Zeitung **berichtet**, **wurde** das Gesetz geändert.*
- **hervorgehen aus + Dat.** · **hinweisen auf + Akk.** · **kommen zu + Dat. (zu dem Ergebnis)**
- **Konjunktiv I für Neutralität:** In der indirekten Rede zeigt der Konjunktiv I, dass es nicht deine eigene Meinung ist.

| Direkte Rede | Indirekte Rede (Konjunktiv I) |
| --- | --- |
| „Bewegung senkt das Risiko.“ | Die Forscher erklären, Bewegung **senke** das Risiko. |
| „Wir haben zu wenig Personal.“ | Die Direktorin sagt, sie **hätten** zu wenig Personal. |
| „Das Projekt ist erfolgreich.“ | Der Minister betont, das Projekt **sei** erfolgreich. |

### Beispielsätze mit Übersetzung

| Deutsch | Persisch |
| --- | --- |
| Der Studie zufolge schlafen Jugendliche zu wenig. | طبق این مطالعه، نوجوانان خیلی کم می‌خوابند. |
| Wie aus dem Bericht hervorgeht, steigen die Kosten. | همان‌طور که از گزارش برمی‌آید، هزینه‌ها در حال افزایش است. |
| Experten sind der Ansicht, dass Kinder mehr Bewegung brauchen. | کارشناسان بر این عقیده‌اند که کودکان به تحرک بیشتری نیاز دارند. |
| Die Forscher erklären, Bewegung senke das Risiko. | پژوهشگران توضیح می‌دهند که تحرک، خطر را کاهش می‌دهد. |

## 5. Alternativen zum Verb „sagen“

Statt immer *sagen* zu verwenden, wählst du ein Verb, das genauer zeigt, **wie** etwas gesagt wird.

### A. Neutral informieren

| Verb | Konstruktion | Beispiel |
| --- | --- | --- |
| erklären | erklären, dass … | Die Ärztin erklärt, dass die Therapie sechs Wochen dauert. |
| berichten | berichten über + Akk. / von + Dat. | Die Zeitung berichtet über den Streik. |
| mitteilen | jdm. etw. mitteilen | Die Firma teilt ihren Kunden mit, dass die Preise steigen. |
| äußern | sich äußern zu + Dat. | Der Minister äußert sich zu den Vorwürfen. |
| erwähnen | erwähnen, dass … | Der Autor erwähnt, dass er selbst Lehrer war. |
| angeben | angeben, dass … | 60 % der Befragten geben an, dass sie wenig Sport treiben. |
| beschreiben | etw. beschreiben | Die Autorin beschreibt ihren Alltag im Krankenhaus. |
| darstellen | etw. darstellen | Der Text stellt beide Seiten dar. |
| informieren | jdn. informieren über + Akk. | Die Broschüre informiert über die neuen Regeln. |
| feststellen | feststellen, dass … | Die Forscher stellen fest, dass die Zahl gesunken ist. |

### B. Etwas betonen

| Verb | Konstruktion | Beispiel |
| --- | --- | --- |
| betonen | betonen, dass … | Die Lehrerin betont, dass Hausaufgaben wichtig sind. |
| hervorheben | hervorheben, dass … | Der Bericht hebt hervor, dass die Kosten gesunken sind. |
| unterstreichen | unterstreichen, dass … | Die Studie unterstreicht, dass Schlaf das Lernen fördert. |
| hinweisen | hinweisen auf + Akk. / darauf, dass … | Experten weisen auf die Gefahren hin. |
| deutlich machen | deutlich machen, dass … | Der Autor macht deutlich, dass er dagegen ist. |

### C. Eine Meinung ausdrücken

| Verb | Konstruktion | Beispiel |
| --- | --- | --- |
| meinen | meinen, dass … | Viele meinen, dass Schule zu früh beginnt. |
| behaupten | behaupten, dass … | Der Politiker behauptet, dass es keine Probleme gibt. |
| vertreten | die Meinung / Auffassung vertreten, dass … | Die Autorin vertritt die Auffassung, dass Bildung kostenlos sein soll. |
| argumentieren | argumentieren, dass … | Gegner argumentieren, dass die Reform zu teuer ist. |
| der Ansicht sein | der Ansicht sein, dass … | Die Eltern sind der Ansicht, dass die Klassen zu groß sind. |
| überzeugt sein | überzeugt sein von + Dat. / davon, dass … | Der Trainer ist davon überzeugt, dass das Team gewinnt. |

### D. Kritik und Widerspruch

| Verb | Konstruktion | Beispiel |
| --- | --- | --- |
| kritisieren | etw. kritisieren | Die Gewerkschaft kritisiert die niedrigen Löhne. |
| bemängeln | bemängeln, dass … | Die Patienten bemängeln, dass die Wartezeiten zu lang sind. |
| einwenden | einwenden, dass … | Man könnte einwenden, dass das zu teuer ist. |
| widersprechen | jdm. / einer Sache widersprechen | Die Expertin widerspricht dieser These. |
| warnen | warnen vor + Dat. | Ärzte warnen vor zu viel Zucker. |

### G. Fragen stellen

| Verb | Konstruktion | Beispiel |
| --- | --- | --- |
| fragen | sich fragen, ob … | Man fragt sich, ob das wirklich nötig ist. |
| die Frage aufwerfen | die Frage aufwerfen, ob … | Der Artikel wirft die Frage auf, ob Noten noch sinnvoll sind. |
| infrage stellen | etw. infrage stellen | Die Studie stellt alte Annahmen infrage. |

### Grammatik

- **Trennbare Verben:** Die Vorsilbe geht ans Satzende: hervor|heben → *Der Bericht **hebt** … **hervor**.* Ebenso: hin|weisen, mit|teilen, an|geben, ein|wenden, zu|geben, ein|räumen, vor|schlagen, dar|stellen, fest|stellen.
- **Im „dass“-Satz** bleibt das Verb zusammen am Ende: *…, dass er die Kosten **hervorhebt**.*
- **„behaupten“** zeigt Distanz: Die Aussage ist nicht bewiesen. **„feststellen“** dagegen bedeutet, dass es eine Tatsache ist.
- **„zugeben“ / „einräumen“** passen gut für Gegenargumente: *Zwar räumt der Autor ein, dass …, aber …*
- **„da“-Wörter:** Bei Verben mit Präposition steht vor einem „dass“-Satz oft *da(r)- + Präposition*: *warnen **davor**, dass …* · *hinweisen **darauf**, dass …* · *überzeugt sein **davon**, dass …*

| --- | --- |

| Abschließend bleibt die Frage, ob … | Abschließend bleibt die Frage, ob die Politik schnell genug reagiert. |

### Grammatik

- **Verb auf Position 2:** *Abschließend **fasse** ich … zusammen.* · *Meiner Meinung nach **sollte** man …* – nicht: ~~Meiner Meinung nach man sollte …~~
- **„Meiner Meinung nach“** = Dativ + nachgestelltes *nach*. Häufiger Fehler: ~~Nach meiner Meinung nach~~ – nur einmal *nach*!
- **Nebensatz als Position 1:** *Betrachtet man alle Aspekte, **wird** deutlich, dass …* – der erste Teil ist ein Bedingungssatz ohne *wenn* (Verb zuerst).
- **zu dem Schluss / Ergebnis kommen** (Dativ) · **halten für + Akk.** · **Wert legen auf + Akk.**
- **Passiv mit Modalverb:** *Zukünftig **sollte** mehr Wert auf Prävention **gelegt werden**.*
