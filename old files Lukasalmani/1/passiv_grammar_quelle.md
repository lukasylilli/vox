## 1. Grundregeln (مجهول‌سازی)
- جمله بدون Akkusativ/Dativ با فعل ناگذرا اصلاً مجهول نمی‌شود: `Er kommt.` → مجهول ندارد.
- **Akkusativ-Satz**: فاعل حذف؛ آکوزاتیو به جای فاعل (به Nominativ!):
  `Ich schreibe einen Brief.` → ✓ `Ein Brief wird geschrieben.` (✗ Einen Brief wird geschrieben)
- **Dativ-Satz**: داتیو بدون تغییر می‌ماند:
  `Er hilft mir.` → ✓ `Mir wurde geholfen.` (✗ Ich wurde geholfen)

## 2. es als Platzhalter
1. پدیده‌های طبیعی/زمان/حالت (حفظی): Es regnet. / Es ist 5 Uhr. / Es gibt ein Problem. / Es geht mir gut.
2. مجهول بدون فاعل: ✓ `Es wird getanzt.` (✗ Wird getanzt)
3. با Akkusativobjekt: `Es wird ein Haus gebaut.`
4. es gibt + Platzhalter: `Es gibt viele Gründe.` / `Es freut mich, dass du da bist.`
5. Scheinsubjekt bei zu/dass: `Es ist wichtig zu lernen.` / `Es ist schön, dass du da bist.`
6. Expletives es (فاعل آخر جمله): `Es kam ein Brief.`
- ⚠️ در جملهٔ dass-دار، es مجهولی نمی‌آید: ✓ `..., dass hier getanzt wird.` (✗ dass es hier getanzt wird)

## 3. Zeitformen-Tabellen
**Vorgangspassiv:** Präsens `wird + P2` · Prät `wurde + P2` · Perfekt `ist + P2 + worden` · Plusq `war + P2 + worden` · Futur I `wird + P2 + werden`
**Zustandspassiv:** `ist + P2` · `war + P2` · `ist + P2 + gewesen` · `war + P2 + gewesen` · `wird + P2 + sein`
**Passiv mit Modalverben:** `Modal + P2 + werden` · `Modal(Prät) + P2 + werden` · `hat + P2 + werden + Modal` · `hatte + P2 + werden + Modal` · `wird + P2 + werden + Modal`
**Lassen-Passiv:** `lässt + Inf` · `ließ + Inf` · `hat + Inf + lassen` · `hatte + Inf + lassen` · `wird + Inf + lassen`
**Rezipientenpassiv:** `bekommt/kriegt + P2` · `bekam/kriegte + P2` · `hat + P2 + bekommen/gekriegt` · `hatte + P2 + bekommen/gekriegt` · `wird + P2 + bekommen/gekriegt`
**Reflexives Passiv (sich lassen):** `lässt sich + Inf` · `ließ sich + Inf` · `hat sich + Inf + lassen` · `hatte sich + Inf + lassen` · `wird sich + Inf + lassen`
